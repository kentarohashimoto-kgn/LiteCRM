# 販売プラットフォーム比較・選定資料

¥100,000のノウハウ教材を販売するためのチャネル比較。
手数料率・上限額などの数値は変動するため **目安（2026年時点の一般的水準・契約前に要最新確認）** として記載。

## 前提：この商品の販売要件

比較の前に、商品特性から来る「譲れない要件」を固定する。

| # | 要件 | 理由 |
|---|---|---|
| 1 | **¥100,000（税別）をそのまま設定できる** | 価格上限のあるプラットフォームは即除外 |
| 2 | **購入者リストを自社で持てる** | 無償アップデート配信・上位商品（伴走/構築代行）への案内が生命線 |
| 3 | **アップデートを追加費用なしで届けられる** | 「育ち続ける商品」が保証の中核（README方針） |
| 4 | **法人の買い方に対応できる** | 第3ターゲット（士業・コンサル）は請求書払い・振込を好む |
| 5 | 特商法表記・返金ポリシーを自社の言葉で置ける | 誠実さブランディングと整合 |
| 6 | 決済手数料が過大でない | 10万円×手数料20%は¥20,000/件。無視できない |

## 推奨：A＋F を主軸、B を拡散用に検討（ハイブリッド）

**主軸 = 自社LP直販（Stripe決済リンク）＋法人向け銀行振込。**

理由：
1. 要件1〜6をすべて満たす唯一の構成
2. 手数料差が大きい ― 100本販売時：直販 約36万円 vs プラットフォーム12% 120万円。**差額84万円**はLP制作費を優に超える
3. **「自社で作って売る」姿勢そのものが商品の証明になる** ― LPも決済も購入者ページもバイブコーディングで作れば、それ自体が実績・教材ネタ・信頼の源泉
4. 購入者リスト＝アップデート配信網＝上位商品（¥30万伴走/¥100万構築代行）の見込み客名簿。ここを他社に握らせない

**補助 = Brain（またはTips）を第2弾タイミングで検討。**
アフィリエイト（購入者による紹介）の拡散力は直販では得にくい。ただし
手数料と価格統制を確認の上、**直販より高い価格**（例：¥110,000）で置き、
直販を「公式最安」にする。

**集客 = note/Xでの実録連載（無料）→ LPへ誘導。**
noteは売り場ではなく客寄せ。02_brandingの発信戦略どおり。

## 実装プラン（直販の最小構成）

すべてバイブコーディングで構築可能な範囲。

1. **LP公開**：lp/index.html をベースに独自ドメインで公開（Vercel）
2. **決済**：Stripe Payment Link（コード不要で発行可能・約3.6%）から開始。
   軌道に乗ったら自前チェックアウトへ
3. **納品**：決済完了メールで購入者専用ページ（パスワード付き）のURLを自動送付。
   教材はWeb閲覧＋PDFダウンロードの2形態
4. **アップデート配信**：購入者メールリストへ告知＋専用ページの更新履歴に追記
5. **法人向け**：LPに「請求書払いをご希望の方」の問い合わせ導線 → 見積書・請求書
   発行（freee連携で省力化可）→ 入金確認後にアクセス発行
6. **法務**：特商法表記／返金ポリシー（デジタル商品につき原則不可・不良時対応を明記）／
   プライバシーポリシー。公開前にテンプレートベースで整備し、不安があれば
   スポットで専門家レビュー
