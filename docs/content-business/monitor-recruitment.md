# 先行モニター募集キット

目的：正規販売開始前に3〜5名へモニター価格で提供し、**「お客様の声」と改善フィードバック**を
獲得する。声はLPの最上部に掲載する（02_branding「信頼の証拠」の最後のピース）。

---

## 募集設計（推奨案・要承認）

| 項目 | 推奨 | 理由 |
|---|---|---|
| 人数 | **5名限定** | 声の多様性（業種違い）確保と対応可能な範囲の両立 |
| 価格 | **¥50,000（正規の半額）** | 無料にしない：無料モニターは実践せず、声も弱い。半額は「本気の人」だけが来る |
| 対象 | 顧客・知人の経営者/営業責任者から**直接声かけ** | 公募より確度が高く、関係性があるので率直なフィードバックが出る |
| 提供条件（交換条件） | ①実践レポート（つまずき箇所の共有）②30分のヒアリング1回 ③実名または社名での感想掲載許可 | 声・改善点・掲載許可の3点をセットで最初に合意する |
| 期間 | 提供から4週間でヒアリング実施 | 教材のゴール（2週間で本番稼働）＋余裕2週間 |
| 特典 | 正規版の全アップデート永続（正規購入者と同等）＋伴走相談30分×1回 | モニターだけの「先に触れる＋直接聞ける」価値 |

## ヒアリング設問（30分・声の採取用）

1. 購入前、何に一番困っていましたか？（Before の言葉を録る）
2. 教材のどこから読み始め、最初に何を作りましたか？
3. 実際につまずいたのはどこですか？（→教材の改善＋FAQ素材）
4. 「安全編」を読んで、行動が変わった点はありますか？（→差別化の証言）
5. どんな会社・人に勧めたいですか？（→ターゲット表現の検証）
6. この教材を一言で表すと？（→キャッチコピー素材）
7. 10万円という価格について、率直にどう感じますか？
