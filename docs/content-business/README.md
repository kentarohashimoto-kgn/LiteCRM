## 伝えたい5つのメッセージ（全ドキュメント共通の柱）

1. **バイブコーディングの有益性** ― 開発の現場を20年離れた経営者が、週末の夜の
   時間だけで、実務に耐えるシステムを作れる時代になった。その実例と再現手順
2. **リスクの認知と、安全なバイブコーディング** ― 便利さの裏にある落とし穴
   （セキュリティ・データ消失・作りっぱなし）を正面から扱い、
   「安全に作る手順」まで含めて教える。ここが他のAI教材との最大の差別化
3. **CRM/SFAとして圧倒的に多機能、しかも安価** ― 商談管理・売上予測・週次レビュー・
   リード管理・一括メール・SEO分析など35超の機能を、インフラ費月数千円で
4. **さまざまなツールとシームレスにつながる** ― Gmail・Googleカレンダー・
   Google Chat・Search Console・自社HPの問い合わせフォームまで、
   既存の仕事の流れに直結できる（すべて本リポジトリで稼働済みの実例）
5. **単体ツールの置き換えとしても優秀** ― タスク・プロジェクト管理（Asana的機能）、
   マインドマップ、案件管理、原価管理、営業分析。バラバラに契約していた
   ツール群を1つに寄せ、月額課金を削減できる

## 10万円の価格設定ロジック

- 比較対象は「書籍(¥3,000)」ではなく **「CRM導入コンサル(¥100万〜)」「SaaS年額(¥50万〜)」
  「受託開発(¥300万〜)」**。その1/10〜1/30で"作る側に回る能力"が手に入る、と位置づける
- さらに「置き換え効果」で語る：Asana・マインドマップ・SFA・分析ツールを
  バラバラに契約すると月数万円。作れば、その固定費が消える
- 情報だけでなく **テンプレート資産（プロンプト集・設計書雛形・要件定義シート・
  安全チェックリスト）** を同梱し「使えば元が取れる道具」として売る
- 返金より **アップデート永続提供** を保証に据える（次項の拡張性がそのまま保証になる）

## 拡張性の方針（足りない部分は今後追加する）

「完成品を売る」のではなく **「育ち続けるコンテンツを売る」**。これを弱点ではなく
セールスポイントに転換する。

### 拡張の3レイヤー

1. **コンテンツ増築（購入者に無償アップデート）**
   - 本体の章追加：新機能を作るたびに「実録章」を追記（本リポジトリが生きた教材源）
   - リスク事例・対策集の増補（安全ノウハウは事例が増えるほど価値が上がる）
   - Q&A・プロンプト集の増補
2. **上位商品への階段（アップセル導線）**
   - ¥100,000: 本コンテンツ（自習型）
   - ¥300,000〜: 伴走ワークショップ（自社CRMを一緒に立ち上げる・少人数）
   - ¥1,000,000〜: 構築代行＋内製化トレーニング（法人向け）
3. **横展開（同フォーマットの別テーマ）**
   - 「バイブコーディングで作る 経理業務システム」「採用管理システム」など、
     本商品を第1弾とするシリーズ化

### アップデートの運用ルール（案）

- 章追加・テンプレ追加は購入者コミュニティ（またはメール）で告知、追加費用なし
- 「現在のバージョン + 今後の追加予定（ロードマップ）」をLPに常時掲載
  → 未完成部分を「今後の価値」として見せる
- 値上げは章追加のマイルストーンごとに実施（早期購入インセンティブになる）
