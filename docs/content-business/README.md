## 拡張性の方針（足りない部分は今後追加する）

「完成品を売る」のではなく **「育ち続けるコンテンツを売る」**。これを弱点ではなく
セールスポイントに転換する。

### 拡張の3レイヤー

1. **コンテンツ増築（購入者に無償アップデート）**
   - 本体の章追加：新機能を作るたびに「実録章」を追記（本リポジトリが生きた教材源）
   - Q&A・失敗事例集・プロンプト集の増補
2. **上位商品への階段（アップセル導線）**
   - ¥100,000: 本コンテンツ（自習型）
   - ¥300,000〜: 伴走ワークショップ（自社CRMを一緒に立ち上げる・少人数）
   - ¥1,000,000〜: 構築代行＋内製化トレーニング（法人向け）
3. **横展開（同フォーマットの別テーマ）**
   - 「バイブコーディングで作る 経理業務OS」「採用管理OS」など、
     本商品を第1弾とする「業務OSシリーズ」化

### アップデートの運用ルール（案）

- 章追加・テンプレ追加は購入者コミュニティ（またはメール）で告知、追加費用なし
- 「現在のバージョン + 今後の追加予定（ロードマップ）」をLPに常時掲載
  → 未完成部分を「今後の価値」として見せる
- 値上げは章追加のマイルストーンごとに実施（早期購入インセンティブになる）
