## 0. 現状構成と弱点

| 層 | 現状 | 弱点 |
|---|---|---|
| DB (Supabase) | **Freeプラン**（共有CPU・RAM 500MB・専有なし） | ①共有CPUのため負荷スパイクで**全クエリ道連れ**（今回の障害）②**7日間アクセスなしで自動一時停止** ③バックアップ機能が弱い（PITRなし）④コネクション上限小 |
| アプリ (Vercel) | Hobby（無料） | ①**商用利用はPro以上が規約要件**（現状はグレー）②同時実行・関数実行時間の上限が小さい ③ビルド遅め |
| 監視 | Sentry(DSN未設定なら無効)・Supabaseログ | 障害を「ユーザーが気づく」まで検知できない（今回も申告ベース） |
| 環境 | **本番のみ**（検証も本番で実施） | 今回のように**検証操作が本番の負荷・データに直撃**する |
| バッチ | Vercel Cron＋Claude Code(方針A) | CRON_SECRET設定待ち。現構成のままでOK |

| 項目 | 内容 | 月額 |
