## 1. 説明文（リードコピー）

### メインコピー

> **「Salesforceを使いこなせる会社」になるのではなく、「営業が勝手に強くなる仕組み」を入れる。**
>
> CATORCE Sales OS は、CRM・SFA・タスク管理・案件原価・名刺・議事録AI・メール追客・SEO集客・バックオフィスまで、**営業活動を中心に8つのSaaS領域を1つのデータベースで連結した営業OS**です。
> ツールを増やすのではなく、ツール間の"継ぎ目"を消す。それが専業SaaSの寄せ集めでは絶対に実現できない、私たちの構造的な強みです。

### サブコピー（用途別）

| シーン | コピー |
|---|---|
| Salesforce利用企業向け | 「Salesforceの機能の8割は使われていない、と言われます。CATORCEは"使われる2割"を日本の営業実務（ヨミ・週次レビュー・7月始まりの年度）に合わせて作り込み、残りをAIと自動化で置き換えました」 |
| BI導入検討企業向け | 「BIはグラフを作る道具。CATORCEは売上の方程式を**診断して処方箋を出す**道具です」 |
| ツール乱立企業向け | 「SFA・タスク管理・名刺・議事録AI・メール計測——月額十数万円分のSaaSと、その連携保守コストが、1本に集約されます」 |
| AI活用を訴求したいとき | 「議事録要約・文字起こし・SEOドラフト・夜間レポート。**AI機能17種、追加の従量課金ゼロ**。"AIオプションは高い"の常識を壊します」 |

### 3行サマリー

1. **多機能**: 商談管理から案件粗利・稼働承認・採用・助成金まで、141画面・8領域を単一DBでカバー。
2. **実務直結**: ヨミ0-9、週次レビュー会議画面、7月開始の会計年度、商談後5分の活動登録——日本の営業現場の"様式"が最初から入っている。
3. **AIと自動化が標準**: 夜間に13本の自動バッチとAIが走り、朝には議事録・レポート・ホットリード通知が揃っている。追加課金なし。

### 4-3. 正直な比較（Salesforceが勝る領域）

提案時に聞かれたら正面から答える。**隠すより「不要性」を語る方が信頼される。**

- **カスタムオブジェクト・項目のノーコード追加** — CATORCEはスキーマ固定。「自由に作れる」は「作り込む人件費が要る」の裏返し、と切り返す。
- **巨大なエコシステム（AppExchange・認定人材市場）** — 中小には「選択肢の多さ」より「最初から揃っている」が効く。
- **CTI・ネイティブモバイルアプリ** — 未対応と明言する。
- ターゲットは「**使いこなせていないSalesforce**」。Flow/Apexを大量にカスタム済みの企業は無理に狙わない。

## 5. 「このツール1本」対応表 — 専業SaaSとの同等性

**CATORCE Sales OS 1本で、以下のSaaSの主用途をカバーできます。**

| 置き換え対象 | 代表製品 | 同等性 | CATORCEで対応する機能 |

| SFA/CRM | Salesforce / HubSpot | **◎ 置き換え可（強）** | §3-1〜3-3の全機能。ヨミ・予測・メール計測・シーケンス・自動化 |
| タスク・PJ管理 | Asana / Backlog | **○ 置き換え可** | ガント・依存関係・サブタスク・繰り返し・@メンション＋商談連動 |
| PSA・工数管理 | クラウドログ 等 | **○ 置き換え可** | 週次稼働＋承認＋月次粗利マトリクス |
| 議事録AI | tl;dv / Notion AI | ○（対面商談は同等以上） | 録音→文字起こし→AI要約→人の確認→CRM反映。オンライン会議ボットは未対応 |
| メール計測・追客 | Mailtrack / 各種シーケンスツール | **◎ 置き換え可** | 開封/クリック計測・シーケンス・予約送信・受信同期 |
| 名刺管理 | Sansan / Eight | △（データ活用は同等以上） | CSV取込→自動マッチング→リード化→エンゲージメントスコア。OCRスキャン入口は未対応 |
| BI・ダッシュボード | Tableau 等 | △（思想転換を提案） | 固定19画面＋診断レントゲン。「グラフを作る」から「処方箋をもらう」へ |
| バックオフィス | kintone | △（研修業なら◎） | 助成金・研修FU・展示会WBS・講師・アンケートの既製アプリ |

## 6. 締めの一言（提案書クロージング用）

> 専業SaaSを8本契約しても、**貴社の営業データは8つに分断されたまま**です。
