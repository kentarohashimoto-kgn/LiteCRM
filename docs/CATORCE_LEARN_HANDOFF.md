## 1. プロジェクトの目的（Why）

1. **MRR戦略の中核**: カトルセは今期3億（チャレンジ5億）・来期10億を目指し、フロー型研修中心（受注の73%）からストック収益への転換を進めている。年度末MRR目標1,000万円のうち、動画学習サービスは主力ブロック（モデル上MRR78万〜120万、来期はアカデミーが10億の最重要商品）。
2. **既存ツールの置き換え**: UTAGE（契約済・月2.5万）とパートナープロップ代理店ポータル（契約済・月20万）は、自社開発が育ち次第**解約する**方針。月22.5万のコスト削減も目的の一部。
3. **AIチャットボット構想**: 将来的に「動画コンテンツの内容も含めて回答してくれるAIチャットボット」を実装したい（代表の明確な意向）。
4. **ツール自体の外販**: LiteCRM外販と同様に「自社で使い倒した実証済みプロダクト」として、Learn基盤自体の外販も検討する。

**Phase 1のつなぎはUTAGEで即日開始可能**（新規契約不要）。Learnはそれを置き換える本命。

### 商品設計の原則（実装に影響するもの）

- **IDは必ず記名式**（メールアドレス紐付け・共有アカウント規約禁止）— 助成金要件・レポート商品・AIパーソナライズの土台
- **Tier 1（アーカイブ）に新作動画を絶対に混ぜない** — 意図的に陳腐化させてTier 2へのアップセル装置にする
- Tier 1は**研修受講企業限定**の販売（単体販売しない）
- アーカイブ1年分（24万円相当）は「追加受講2名 or 5名定価死守」の営業特典として進呈される運用がある → **特典付与（期限付き無償アクセス）を管理画面から発行できること**
- ID増加は即時（翌月課金）、削減は年次更新時のみ — 契約管理に反映

### 更新コンテンツの運用（月4本）

- セミナー録画2本（実施済みセミナーの流用・追加コストゼロ）＋ AIツール解説2本（台本AI生成→収録30分→AI編集、1本0.5人日）
- YouTubeと「二毛作」: 同じ収録から無料ダイジェスト（集客）と有料フル版（Learn）を作る
- コンテンツ台帳: 動画ごとにタグ（対象ツール・レベル・公開日）を持ち、ツールのアップデート時に差し替えタスクを自動生成したい

## 3. 助成金要件 → Learnの必須機能（最重要）

人材開発支援助成金「**定額制訓練**」（サブスク型eラーニング、経費助成 中小目安60%）の対象にすることが営業戦略の柱。
「助成金対応eラーニング」を名乗れることがUTAGE/Vimeo等との決定的差別化になる。

対象化のためにLearnが**必ず**持つべき機能（※最終要件は社労士確認中。#25施策で提携予定）:

1. **記名IDごとの視聴ログ・学習時間記録**（いつ・誰が・どの動画を・何分視聴したか）
2. **標準学習時間つきのカリキュラム管理**（コース単位で標準学習時間を明示できる構造）
3. **修了管理・修了証発行**
4. **受講者単位・契約期間単位の利用実績レポート出力**（助成金申請書の添付資料になる形式）

あわせてライブ研修側はリスキリング支援コース（経費75%・上限30万/人目安）を利用中。「36万→実質9万/人」「Light月5万→実質月2万」が営業トーク。

## 4. 機能要件（フェーズ分け）

### MVP（目標: 2026年11月着手 → 2027年1月のアカデミーLightローンチに間に合わせる、見積15〜20人日）

- マルチテナント企業管理（契約プラン・ID数バンド・契約期間・特典付与）
- 記名ID招待（メールドメイン制限＋招待制）、解約時の契約終了日自動停止
- 動画配信（署名付きURL・ダウンロード抑止）
- コース／カリキュラム構造（コース＞レッスン、標準学習時間、タグ）
- 視聴ログ（再生位置・完了率・学習時間）
- 管理画面2種: カトルセ運営用（テナント・コンテンツ・特典管理）／顧客管理者用（自社メンバー招待・視聴状況閲覧）

### Phase 2（Tier 3商品化・LiteCRM連携）

- 受講率レポート自動生成（部門別視聴率・人気コンテンツ・未視聴者リスト＋Claude APIによる講評）— **人手ゼロでTier 3の中核商品を生産する**
- 理解度テスト・AIリテラシー診断（#10）連携、修了証
- **LiteCRM連携**: 視聴ログを商談テーブルへ（「視聴が減った→フォロー」「特定部門の視聴率が高い→研修提案」の営業トリガー自動化）。これは既製LMSでは作れない自社開発の最大の理由
- 助成金申請用レポートのエクスポート

### Phase 3（AIチャットボット・外販）

- 動画コンテンツRAGチャットボット: 全動画の文字起こし→埋め込み→「この操作どうやるんだっけ？」に該当動画の該当箇所つきで回答。研修アーカイブの自社文脈（顧客ごとの質疑）もテナント別に学習
- 外販モード: セルフオンボーディング・課金（Stripe）・利用量計測（LiteCRM外販と共通の課金基盤にできると理想）

## 5. 技術方針（推奨・実装スレッドで最終判断）

- **スタック: Next.js + Supabase + Vercel** — LiteCRM（本リポジトリ）と同一。LiteCRMの実証済みマルチテナントパターン（全テーブル `tenant_id`＋RLS）を流用する
- **動画配信: Cloudflare Stream か Mux** — 保存・配信とも従量課金（月数千円規模から）。ユーザー数課金が発生しない=「原価のかからない商品」を守る。署名付きURL対応
- 認証: Supabase Auth（メール招待・ドメイン制限）
- 文字起こしパイプライン: 収録→自動文字起こし→（a）字幕 （b）Phase 3のRAGコーパス、を最初から貯める設計にする（後付けは高くつく）
- LiteCRMとの関係: 別アプリ・別リポジトリでも良いが、テナント/顧客マスタはLiteCRMのaccountsと突合できるキーを持つこと
