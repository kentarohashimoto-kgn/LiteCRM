## 4. 全ページ共通の必須要素（カトルセが勝てる唯一の理由）

一般論の「生成AI研修とは」では大手と比較メディアに勝てない。各サービスページに必ず:

- 実績企業・**累計2,000名以上**の受講人数・満足度
- **導入前後の変化**（削減時間・開発工程10〜20%／テスト工程30%の生産性改善）
- 具体的な成果物・実施期間・対象人数
- **研修後90日間の定着方法**（他社が書けない一次情報）
- 担当者コメント
- 料金の目安（プラン別の支援範囲。「相談だけ/実行支援込み/開発込み」の違い）

現在この情報は記事や旧サイトに分散している。**ページ設計と同時に集約する。**
