# HP担当（ClaudeDesign）への依頼書 — SEO施策のためのデータ提供・設定作業

作成: 2026-07-30 / 依頼元: CATORCE Sales OS（LiteCRM）SEO運用
この文書は単体で読めるように書いてあります。**そのままコピーしてClaudeDesignに渡せます。**

## 背景（1分で）

catorce.jp のSEOを「狙ったキーワード×対策ページ」の台帳で運用し始めました。
現在43ページ・211語を設計済みで、うち13ページは既存ページ（/st/ 配下）に紐づけ済みです。
ただしCRM側からは catorce.jp のサーバー・CMSに直接アクセスできないため、
Search Console経由で「Googleに表示されたページ」しか見えていません。
**表示されていないページは存在自体が見えない**ので、以下のデータ提供と設定作業をお願いします。

---

## 依頼1: /st/ 配下の全ページ一覧の提供【最優先・データ提供】

Search Consoleに出てこないページも含めた**完全なページ一覧**が欲しいです。

**欲しい形式**（CSV・スプレッドシート・Markdown表のいずれか）:

| 列 | 内容 |
|---|---|
| URL | 例 `/st/training-10h.html` |
| titleタグ | 現在のtitle文字列そのまま |
| meta description | 現在の文字列そのまま |
| ページの役割 | LP / 記事 / キャンペーン / 採用 など一言 |
| 最終更新日 | 分かる範囲で |

sitemap.xml があればそのURL共有だけでも第一歩になります。
対象は `/st/` 配下全部＋ `/news/` 配下のAI関連ページ。

**用途**: 既存13ページ以外にも紐づけられるページがないかの照合と、
リライト時の現状title/description把握。

## 依頼2: CMSデモページのnoindex設定【設定作業・軽微】

以下がGoogleにインデックスされ、検索結果に表示されています（Search Console実測）。
サイト品質評価を下げる恐れがあるため **noindex（`<meta name="robots" content="noindex">`）** をお願いします。

- `/company/sample-company*/` 配下（CMSサンプルページ）
- `/service/sample-service*/` 配下（同上）

同種のテスト・サンプルページが他にもあれば同様に。

## 依頼3: 問い合わせフォームへの計測スニペット設置【最重要・設定作業】

問い合わせがどのページ・どの検索キーワード経由で来たかを計測するスニペットの設置です。
現状 **流入元ページの記録率が0%** で、SEO→問い合わせ→売上の接続が計測できていません。

仕様書: リポジトリの `docs/HP_INQUIRY_FORM_INTEGRATION_2026-07.md` §4.4
（sessionStorageにファーストタッチのランディングページ・リファラを保存し、
フォームのhiddenフィールドに載せて送信する十数行のJSです。個人情報は扱いません）

## 依頼4: 確認したいこと3点【質問への回答だけでOK】

1. **バイブコーディング研修の専用LP**はどのURLですか？
   現在 `/st/knowledge-vibe-coding.html`（解説記事）を暫定の対策ページにしています。
   専用LPが別にあればそちらに切り替えます。
2. **`/st/training-10h.html` と `/st/training-dept.html`** は何のページですか？
   （10時間研修？部門別研修？対象者と内容を一言で）
3. **`/st/prompt-campaign.html`** は現在も有効なキャンペーンですか？
   プロンプト研修LPを新設予定のため、統合するか併存させるかを決めたいです。

## 依頼5: 今後の作業予告【対応不要・心づもりだけ】

SEO台帳に基づき、今後こういう依頼が順次来ます:

- **既存ページのtitle・見出しのリライト**（例: `/st/training-lp.html` のtitleを
  「AI研修のご案内」→「法人向け生成AI研修｜ChatGPT・Copilot・Gemini・Difyを実務定着｜カトルセ」）
- **新規LPの追加**（Claude研修 / AIエージェント研修 / Copilot研修 / 費用相場 / 導入事例 など）
- **既存記事から新規LPへの内部リンク追加**（リンク元リストは台帳側で管理済み）

各ページには「累計2,000名以上の研修実績」「研修後90日間の定着支援」などの
実績数字を必ず入れる方針です。実績データの原本の所在が分かれば教えてください。

---

## やりとりの方法

- データはCSV / スプレッドシート / Markdownのどれでも構いません
- 質問への回答はテキストでOK。もらった内容はSEO台帳（CRM）に反映します
- 優先順: **依頼3（計測スニペット）→ 依頼1（ページ一覧）→ 依頼2（noindex）→ 依頼4（確認）**
