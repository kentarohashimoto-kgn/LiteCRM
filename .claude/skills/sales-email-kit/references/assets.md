# 共有アセット（営業メールで送る資料リンク／添付）

このファイルが**資料の一元管理場所（single source of truth）**です。
資料が増減・差し替えになったら **この表を編集するだけ**で、`sales-email-kit` の
全メール種別（お礼／提案書送付／資料送付 等）に反映されます。

## 直接本文に貼るリンク

| 用途 | 種別 | リンク | 本文への貼り方 | 状態 |
|---|---|---|---|---|
| サービス事例 | Canvaサイト | https://ai202504.my.canva.site/ai-20260602 | `▼サービス事例\nhttps://ai202504.my.canva.site/ai-20260602` としてそのまま貼る | 標準・有効 |

| AI研修 説明資料 | （最新版を直近のSENTメールまたはDrive/Boxで確認） | 添付 or リンク | 相手・テーマに応じて差し替え |
| （追加はここに行を足す） |  |  |  |

## 更新のしかた

- **リンクを差し替える**：該当行のURLを書き換える。
- **資料を増やす**：表に1行追加。`用途`（何のとき使うか）を明記しておくと、メール生成時に
  適切なものを自動選択しやすい。
- **テーマ別の出し分け**：`備考`に「研修向け」「開発向け」等の条件を書いておく。
- 迷ったら本文には貼らず「別途お送りいたします」に留め、確実なリンクだけ直貼りする。

> メール生成時は必ずこのファイルを読み、`状態=有効`のリンクを本文に反映すること。
> Canvaリンクは常に**フルURLをそのまま**貼る（短縮・加工しない）。
