1. 全体フロー（1枚図）

リード獲得からアポまでは、次の6ステップが自動と手動を織り交ぜて流れます。人がやるのは「取込」「送信ボタン」「電話」だけで、優先順位付け・計測・通知はシステムが行います。

1 手動リード取込展示会CSV or 名刺→リード化。取込と同時にFitスコア自動付与
2 自動優先順位付けFit(属性)×Engagement(反応)でP1〜P5のグレード判定
3 手動一括お礼メール絞り込み or チェック選択→テンプレ差し込み→送信
4 自動反応の計測開封・クリック・資料閲覧・返信を15分ごとにスコア化
5 自動ホット通知ベル通知＋Chat DM。「今日のアポ・AC」の🔥リストにも表示
6 手動架電→アポ通知から2タップで発信。アポが取れたら「案件化」
💡 鉄則：開封・クリックの通知が来たら、その場で電話。相手が今まさにこちらを見ているタイミングが最も繋がりやすく、話が早い。

2. リードの取込（2つの入口）

入口A：展示会リストのCSV取込

  1. リード 画面右上の「取込」→ CSVをアップロード
  2. 列マッピングを確認（会社名・氏名・メール・役職などは自動で対応付け。手で修正も可能）
  3. 流入イベント名（例: AIDX展）と獲得日を指定して実行
  4. 取込完了と同時に全リードへFitスコアとランク(S〜D)が自動付与される

入口B：名刺（Eight等）→リード化

  1. 名刺情報 画面で「名刺を取込」（Eight CSVなど）
  2. タグ（展示会名）や交換日で絞り込む
  3. 右上の「リード化」ボタン → 未リード化の名刺がまとめてリードに変換される
リード化の挙動内容
重複防止同じメールアドレスのリードが既にある場合は新規作成せず既存リードへ紐付け（二重アプローチを防ぐ）
引き継ぐ情報会社・氏名・メール・電話・部署・役職・交換日・メモ・ランク
スコア変換後に自動でFitスコアを付与

3. 優先順位付けの仕組み（2軸スコア）

1つの点数に混ぜると「大企業だが無反応」と「小規模だが今すぐ客」が同点になってしまうため、2つの軸を分けて持っています。

軸1：Fitスコア（属性の良さ・0〜100点）— 登録情報から自動計算

観点配点判定材料
規模20従業員数（1000名以上=20 / 300以上=15 / 100以上=10 / 30以上=5）
役職20役員クラス=20 / 部課長=10（役職名から自動判定）
課題25ニーズの強さ（高=25 / 中=12）
時期15導入時期（今すぐ=15 / 近々=10）
予算20予算の有無（あり=20 / 検討中=10）

合計点でランクが決まります：S(80+) / A(65+) / B(50+) / C(35+) / D。手動で設定したランクは自動計算で上書きされません。内訳（なぜこの点数か）はリード詳細に表示されます。

軸2：Engagementスコア（行動の熱さ）— メール反応・接点から自動加点

メール開封+1（同じメールは1日1回まで）
リンククリック+3
資料閲覧（PDF/Driveリンク）+5
メール返信+8（最強のシグナル）

このほか、セミナー参加・展示会名刺交換・架電などの接点も加点されます。合計点でエンゲージランク：S(30+) / A(15+) / B(7+) / C(3+) / D。

💡 テンプレの資料リンクをPDFまたはGoogle DriveのURLにすると、クリックが「資料閲覧(+5)」として高く評価され、ホット検知の精度が上がります。

4. 優先グレード P1〜P5（マトリクス）

2つの軸を掛け合わせて、「今日誰に何をするか」を1つのグレードに落とします。リード詳細・🔥リストに表示されます。

反応 高（15pt以上）反応 中（3pt以上）反応 なし（3pt未満）
Fit S/A（65点以上）P1 今すぐ本日中に架電P2 今週今週中に接触（架電優先）P3 育成メール中心でナーチャリング
Fit B（50点以上）P2 今週今週中に接触P3 育成標準フォローP4 低頻度低頻度メールのみ
Fit C/D・不明P3 育成メールで反応を確認P4 低頻度低頻度メールのみP5 見直し四半期見直しで対象外検討

考え方：属性が良くても無反応なら追いかけ過ぎない（P3）。属性が低くても反応があれば低コストで確認する（P3）。両方揃った相手（P1）に電話の時間を集中する。

5. 一括メールの送り方

手順

  1. リード 画面のリード一覧タブで対象を絞り込む
    • 流入（展示会名）、決着、ランクで絞る。ランクは複数選択可（例: SとAだけ）
    • さらに細かく選びたい時は、行頭のチェックボックスで対象を個別に選ぶ（ヘッダーのチェックでページ全選択）。チェックがある場合はチェックした相手だけに送られます
  2. 「✉️ 一括メール」ボタン → テンプレートを選択
  3. セグメント名を入力（例:「AIDX展1日目・S/Aランクお礼」。後の反応分析でこの名前で集計されます。空欄なら自動命名）
  4. 対象内訳と差し込みプレビューを確認 → 「N件に送信」

送信前に自動で除外されるもの（安全ガード）

除外対象理由
メールアドレスなし・形式不正送れないため（電話でアプローチ）
同一アドレスの重複同じ人に2通送らない（優先度の高い方だけ残す）
配信停止済み本人が停止を希望（法令対応。解除は管理者へ）
同じテンプレを送信済み再実行しても二重送信にならない（安心して押し直せる）

1回の送信は最大300件。20件ずつ順に送られ、画面に進捗が表示されます。途中でエラーが出ても送信済み分は記録され、再実行すると残りだけが送られます。

6. メールテンプレ — どこが自動で変わるか

テンプレは メール → テンプレート で編集します。1通のメールは次の3種類の部品でできています。

自動で変わる件名・本文中の {contact}（相手の氏名）・{company}（会社名）・{sender}（差出人名）が、リードごとに差し込まれる
固定（自分で書く）挨拶文・展示会名・案内文・資料リンクのURLなど、テンプレに書いた本文はそのまま送られる
システムが自動付与開封計測（見えない1pxの画像）／クリック計測（URLの自動ラップ）／配信停止フッター。テンプレに書く必要はなく、消すこともできない
差し込み変数展開される内容データ元
{contact}相手の氏名（例: 山田 太郎）リードの担当者名
{company}会社名（例: 株式会社〇〇）リードの会社名
{sender}差出人名（例: 橋本 健太郎）メール送信アカウントの差出人名
⚠ 変数のスペルを間違えると（例: {contct}）そのまま文字として送られます。送信前のプレビューで、先頭リードでの実際の差し込み結果を必ず確認してください。
🔍 今どんなメールが送られるの？ → アプリの 送信プレビュー（対比） を開くと、現在登録されているテンプレートを選んで「左＝設定画面の原文（変数ハイライト付き）／右＝相手の受信画面イメージ（差し込み後・計測リンク・配信停止フッター込み）」を左右対比で確認できます。サンプルの氏名・会社名も自由に変えて試せます。

7. 反応の計測とスコア加点

送信後、相手の行動は次の流れで自動的にスコアへ変わります（15分間隔で処理）。

相手の行動開封・クリック・返信メール内の計測が反応を検知
15分ごとスコア加点+1〜+8を接点履歴に記録（同じ反応は二重計上しない）
同時グレード再判定Fit×Engagementのマトリクスを再計算
条件一致通知ベル＋Chat DM＋🔥リスト
  • 反応の履歴はリード詳細のエンゲージメント欄に「メール開封 +1」「資料閲覧 +5」のように日付つきで並びます
  • 開封はメールソフトの仕様上近似値です（画像を表示しない相手は検知できない）。クリック・返信は確実に取れるため、重み付けもクリック・返信を重くしています
  • 返信はシーケンス（多段フォロー）の自動停止条件にもなります（返信をくれた人に機械的な追客を続けない）

8. 閾値を超えた時のアクション・通知

何が起きたらどこに通知されるかあなたがすること
リンククリック / 資料閲覧 / 返信アプリ内ベル通知 ＋ Google Chat DM（Chat連携済みの人）今すぐ架電。相手が見ているその瞬間が最も繋がる
メール開封のみアプリ内ベル通知のみ（通知疲れ防止のためDMは送らない）🔥リストで様子見。他の反応が重なったら架電
スコアが閾値(15pt)を超え P1昇格「🔥 〇〇社がP1(今すぐ対応)に昇格」がベル＋Chat DMに本日中に架電。P1は今日のTOP優先
  • 通知はリードの担当者に届きます。担当者が未設定のリードは、owner / admin / インサイドセールスのロールを持つ全員に届きます
  • 通知を開くとリード詳細へ直行 → 電話番号の「発信」からワンタップで架電できます
  • 反応のあった直近48時間のリードは、今日のアポ・AC 画面上部の「🔥 反応のあったリード」に理由つきで常時表示されます（通知を見逃してもここで拾える）

9. セグメント履歴・流入別分析の見方

メール → セグメント分析（またはテンプレート画面の「セグメント分析」ボタン）で開きます。

① 送信セグメント履歴

一括送信1回 = 1セグメントとして自動記録されます。

例: 7/29 18:02 AIDX展1日目・S/Aランクお礼 送信20件 開封率 55% クリック率 20% 返信率 5%
  • 送信時に付けたセグメント名・テンプレ・実行者・送信/失敗数・開封率/クリック率/返信率が1行で見えます
  • 「1日目と2日目でお礼文面を変えたらどちらが反応が良いか」のような文面・タイミングの比較に使ってください

② 流入別の反応・アクション状況

展示会・セミナーなど流入（取込イベント）ごとに、リード数 → メール送信 → 開封/クリック/返信 → 架電着手率 → アポ → 商談化 のファネルを横断で見ます。

  • 反応率が高い流入 = 見込みの濃いリスト。架電の時間をここに寄せる
  • 架電着手率が低い流入 = フォロー漏れ。リストの消化を優先する
  • 展示会の出展判断（来年も出るか）の材料としても使えます

10. 配信停止と法令対応（必読）

  • 一括送信・シーケンスの全メールに配信停止リンク付きのフッターが自動で付きます（特定電子メール法対応）。テンプレに書く必要はありません
  • 相手が停止リンクを押すと即座に停止リストへ登録され、以後の一括送信・シーケンス・個別送信すべてから自動で除外されます
  • 停止された相手に手動で送ることもできません（送信時にブロックされます）
  • 誤って自分でテスト中に停止してしまった場合は管理者に解除を依頼してください
⚠ 一括メールは「接点をいただいた方へのご案内」が前提です。接点のない購入リスト等への送信は行わないでください（法令リスクに加え、送信元ドメインの評価が下がり全メールが届きにくくなります）。
